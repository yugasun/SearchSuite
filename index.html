SearchSuite translates provider APIs into one consistent TypeScript interface. You stay in control of provider choice and application logic.

01 / TYPED

Provider-aware types

Get provider-specific options and response types from your selection. Catch configuration mistakes at compile time.

02 / NORMALIZED

Consistent responses

Normalize results, usage, latency, warnings, and errors while keeping provider-specific features available through typed options.

03 / EXPLICIT

No hidden behavior

Each call makes at most one provider request. No implicit retries, fallbacks, cross-provider routing, or caching.

04 / CONTENT

Search and fetch

Retrieve web content from supported providers with explicit content types and truncation status.

05 / NATIVE

Native web APIs

Built on fetch, AbortSignal, and standard ESM. Zero runtime dependencies. Requires Node.js 24 or newer.

06 / PORTABLE

Framework independent

Use the same SDK in server-side and agent applications. The core package does not depend on an application framework.

Up and running

A few lines of code
to start searching.

Install the SDK, choose a provider, and make a familiar async/await call. Switch providers by changing the provider field.

Read the getting started guide ↗
quick-start.ts
// npm install searchsuite
import { SearchSuite } from 'searchsuite'

const client = new SearchSuite()
const response = await client.search({
  provider: 'tavily',
  query: 'Recent advances in AI agents',
  maxResults: 5,
})

for (const result of response.results) {
  console.log(result.title, result.url)
}
