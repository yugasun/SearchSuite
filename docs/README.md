# SearchSuite documentation

SearchSuite is a framework-independent, ESM-only TypeScript SDK for using Baidu,
Doubao, Tavily, Exa, and Serper through one typed search API.

## Use SearchSuite

- [Getting started](getting-started.md) — install the package, configure
  credentials, run a first search, and troubleshoot common usage errors.
- [Providers](providers.md) — choose a Provider and understand credentials,
  provider options, limits, and the capability matrix.
- [API reference](api-reference.md) — use the public request, response, warning,
  error, timeout, and cancellation contracts.

## Contribute and maintain

- [Development](development.md) — install dependencies, run offline and live
  tests, validate the build, and check a packed artifact.
- [Architecture](architecture.md) — understand the client, lazy registry,
  provider adapter boundary, and v0.1 non-goals.
- [Roadmap](roadmap.md) — see the planned work beyond the v0.1 compatibility
  layer.
- [Technical design](../TECHNICAL_DESIGN.md) — read the implementation baseline
  and invariants.
- [Contributing guide](../CONTRIBUTING.md) — prepare a change or add provider
  coverage.
- [Security policy](../SECURITY.md) — report a vulnerability without disclosing
  credentials or sensitive provider data.
- [Support guide](../SUPPORT.md) — choose the right channel for questions, bugs,
  feature requests, and security reports.
